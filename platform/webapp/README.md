# @morphora/webapp

Next.js 14 App Router console for Morphora (dual-speed CIO war room).

```bash
pnpm --filter @morphora/webapp dev
# or from repo root:
pnpm dev:web
```

Defaults: API `http://127.0.0.1:4000`, demo login `admin@demo.local` / `sandbox-admin-8`, or `X-API-Key: morphora_demo_local_dev_key`.
