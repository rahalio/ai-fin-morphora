# Morphora — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### CIO

- As a CIO, I want my week run against the four shapeshifter roles, so that I do not collapse back into ticket triage.
- As a CIO, I want sensing recommendations with hype scores, so that I can challenge vendor theatre in exco.
- As a CIO, I want run vs change spend against the 75–80% maintenance benchmark, so that I can prove dual-speed progress.

### Enterprise architect / bridge lead

- As an architect, I want each core system tagged modernise/replace with dependencies, so that we stop accidental brittle change.
- As an architect, I want change-fast initiatives to declare their coupling to careful-run systems, so that dual-speed is real rather than slogan.

### Ecosystem / vendor lead

- As a vendor lead, I want partner criticality and concentration views, so that we do not outsource systemic capability blindly.
- As a vendor lead, I want hype-filter outcomes tied to procurement gates, so that rejected tech cannot re-enter via a business-unit PO.

### Innovation / accelerator lead

- As an innovation lead, I want challenger experiments with kill metrics, so that the portfolio stays option-rich without becoming a museum.
- As an innovation lead, I want build/buy/partner recommendations per capability, so that we only build differentiators.

### CFO / risk partner

- As a CFO partner, I want IT investment decisions linked to fiscal accountability, so that strategy talk still balances.
- As a third-party risk partner, I want concentration breaches to block scale of dependent initiatives, so that resilience is not optional.

### CIO chief of staff

- As chief of staff, I want a single operating rhythm (sensing → dual-speed plan → ecosystem → challenger), so that the office produces decisions not decks.
